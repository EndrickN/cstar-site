One more step to unlock STANDARD

Your licence is tied to the machine you will run CSTAR on, so it cannot be issued until the application has told you its Hardware ID. That takes about a minute.

1

Download and run CSTAR

If you have not installed it yet, download the application and run it. No installer, no account — it opens straight into DEMO mode.

2

Copy your Hardware ID

Press 🔑 Activate in the toolbar. The dialog shows a 16-character code — use Copy HWID to Clipboard.

A1B2-C3D4-E5F6-7890 this is only an example — yours will differ

It is derived from your Windows installation and processor. It contains no personal data, and it does not change when you move house, switch networks or use a VPN.

3

Send it over

Use the form below. Your key comes back by email, usually within a few hours. Paste it into the same dialog and STANDARD unlocks immediately — no restart.
