One more step to unlock STANDARD

Your licence is tied to the machine you will run CSTAR on, so it cannot be issued until the application has told you its Hardware ID. That takes about a minute, and then your key arrives by email.

1

Download and run CSTAR

If you have not installed it yet, download the application and run it. No installer, no account — it opens straight into DEMO mode.

2

Copy your Hardware ID

Press 🔑 Activate in the toolbar. The dialog shows a 16-character code — use Copy HWID to Clipboard.

A1B2-C3D4-E5F6-7890 this is only an example — yours will differ

It is derived from your Windows installation and processor. It contains no personal data, and it does not change when you move house, switch networks or use a VPN.

3

Send it over and watch your inbox

Send us the Hardware ID with the form below. Your licence key comes back by email — paste it into the same dialog and STANDARD unlocks immediately, no restart needed.

Keys are issued by hand, not by a robot. Expect a few hours, and up to one business day if you have caught us asleep. Nothing more is needed from you in the meantime — and the demo keeps working while you wait.
